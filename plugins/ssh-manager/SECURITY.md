# 安全说明

## 凭据保护

仓库使用 AES-256-GCM 加密保存服务器配置和敏感凭据。随机生成的 256 位仓库密钥单独保存：

- Windows 优先使用当前用户 DPAPI 保护密钥。
- 如果受限或非交互式 Windows 会话无法使用 DPAPI，则回退为当前 Windows 用户 ACL 保护的密钥文件。
- POSIX 系统使用权限为 `0600` 的密钥文件。

只有 MCP 服务在准备建立连接时才会在内存中解密凭据，MCP 工具输出不会包含密码或私钥口令。

## 确认机制

MCP 服务会在内部判断命令风险。只有严格白名单中的单条只读命令可以直接执行。上传、下载、部署、重启、写文件、修改权限、安装软件包、删除文件等操作都会触发 Codex 的 `elicitation/create` 确认表单。

只有表单提交结果为同意且 `approve` 为真时，操作才会执行。拒绝、取消或确认界面不可用时，不会对远程服务器做任何修改。服务不提供绕过确认的令牌或接口。

## 限制

- 同一 Windows 用户下的恶意软件或管理员权限程序，仍可能读取进程内存或本机数据。
- 发送到远程服务器的密码由系统 OpenSSH 客户端处理。
- `hostKeyPolicy=insecure` 会关闭主机指纹校验，只应在受控排障时临时使用。
- 自动化 `sudo` 需要提前配置免交互授权。本插件不会替用户输入交互式 sudo 密码。
